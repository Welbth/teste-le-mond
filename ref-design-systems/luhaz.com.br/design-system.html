Motion & Interações

  • Category Zoom Effect: Os cards de categoria aplicam zoom gradual na imagem de fundo utilizando transições CSS de transform 0.5s ease.
  • Navigation Underline Transition: Underlines fluidos que se estendem sob os links de navegação no menu ao passar o mouse.
